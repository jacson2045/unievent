    Pruebas integrales¶

    Las pruebas integrales verifican el sistema real de punta a punta: todos los microservicios, PostgreSQL, Kafka, Eureka y el API Gateway levantados con Docker Compose. Se comunican con el backend exactamente como el frontend: a través del gateway.

    • Código: tests/e2e/flujo-principal.test.mjs
    • Herramienta: ejecutor de pruebas nativo de Node.js (node:test), sin dependencias adicionales.
    • Cada ejecución registra usuarios nuevos (sufijo único), por lo que se puede repetir sin limpiar datos.
    • Usuarios: dos estudiantes (A y B) y dos organizadores (O y P) para verificar la autorización a nivel de objeto, más el administrador inicial.

    Cómo ejecutarlas¶

    Con el sistema levantado (docker compose up -d):

    # Sin instalar nada (contenedor de Node en la red de Docker)
docker compose --profile tests run --rm e2e

# Con Node.js 22+ instalado (además genera tests/e2e/reportes/resultado-junit.xml)
pnpm test:e2e

    Los casos que dependen de credenciales externas se marcan como omitidos (skipped) si faltan: CP-23 requiere credenciales de prueba de Mercado Pago y CP-27 requiere ADMIN_PASSWORD.

    Hallazgo detectado por las pruebas¶

    H-04 — Pagos marcados como aprobados sin haberse pagado. La primera ejecución de CP-23 falló: al repetir la solicitud de pago, el sistema respondía "La inscripción ya tiene un pago aprobado".

    • Causa: la referencia que se enviaba a Mercado Pago (external_reference) era el id autoincremental del pago. Al iniciar el entorno Docker con una base de datos nueva, los ids se repitieron, y la consulta a Mercado Pago encontró pagos aprobados antiguos de la misma cuenta de pruebas con esa referencia. El pago nuevo se marcaba como aprobado y la inscripción se confirmaba sin pago.
    • Corrección: cada pago tiene una referencia externa propia (UUID) en la columna referencia_externa (migración V7). Los pagos antiguos conservan su referencia anterior.
    • Verificación: CP-23 comprueba ahora que un pago recién creado sigue PENDING y la inscripción PENDIENTE. La suite pasa 27/27.
