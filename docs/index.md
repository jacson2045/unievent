# UniEvent Pay

Bienvenido a la documentación técnica de **UniEvent Pay**, una plataforma web para la gestión de eventos universitarios.

## Objetivo del proyecto

Centralizar la publicación de eventos, las inscripciones, los pagos electrónicos, el control de asistencia y las notificaciones en una sola plataforma.

## Funcionalidades principales

| Funcionalidad | Descripción |
|---|---|
| Usuarios | Registro, autenticación y roles |
| Eventos | Publicación y consulta de eventos |
| Inscripciones | Registro de participantes |
| Pagos | Gestión de pagos electrónicos |
| Asistencia | Control mediante códigos QR |
| Notificaciones | Comunicación de eventos del sistema |
| Administración | Supervisión de la plataforma |

## Tecnologías utilizadas

- **Frontend:** React, Vite, TypeScript y Tailwind CSS.
- **Backend:** Java 21 y Spring Boot.
- **Base de datos:** PostgreSQL.
- **Mensajería:** Apache Kafka.
- **Seguridad:** JWT.
- **Resiliencia:** Resilience4j.
- **Observabilidad:** Prometheus y Grafana.
- **Documentación:** MkDocs Material.

## Roles del sistema

- **Estudiante:** explora eventos, realiza inscripciones y consulta pagos.
- **Organizador:** administra eventos y participantes.
- **Administrador:** supervisa y gestiona la plataforma.
